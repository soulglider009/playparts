# good-water

A focused Agent Skill for turning flat, generic 2D web-game water into a layered, responsive game surface.

## What it captures

- Depth before decorative detail
- Multiple unsynchronized motion scales
- Controlled highlights and caustics
- Speed- and direction-aware object wakes
- Shoreline and contact effects with a visual cause
- A practical Canvas 2D implementation reference
- A verification checklist that compares the result at normal game scale

## Current status

This is the first Playparts experiment. The live site is both its reference implementation and its initial before-and-after proof. Formal cross-model baseline runs are intentionally not claimed yet.

## Try it

Copy the `good-water` directory into the skills location used by your agent, then ask it to use `good-water` to improve a lake, river, or ocean in an existing 2D web game.

## Scope

The first version targets stylized Canvas 2D games. It does not cover physically accurate fluid simulation or photorealistic 3D oceans.
